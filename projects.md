    <p class="project-section-title"><strong>Overview</strong></p>
    <p>
      Pixel Pets is a full-stack virtual pet adoption and care platform where users can create, adopt, and interact with
      digital pets that grow and respond over time. It blends playful pixel-art visuals with a robust backend architecture.
    </p>

    <p class="project-section-title"><strong>Highlights</strong></p>
    <ul>
      <li>Built a React front end with reusable components for adoption flow, profiles, and pet interactions.</li>
      <li>Developed a Spring Boot REST API managing users, pets, and actions to support full CRUD.</li>
      <li>Designed a MySQL schema with clear relationships and an ERD for maintainability and growth.</li>
      <li>Created a responsive UI with polished micro-interactions and a retro-inspired visual theme.</li>
    </ul>

    <p class="project-section-title"><strong>Impact</strong></p>
    <p>
      Demonstrates end-to-end full-stack delivery: UX → API → database design → deployment, with a focus on clarity and fun.

    <p>
      Furever Friends Rescue is a story-driven React app that simulates a friendly pet adoption experience.
      Visitors can browse adoptable animals, read personality-filled bios, and submit adoption interest forms.
    </p>

    <p class="project-section-title"><strong>Highlights</strong></p>
    <ul>
      <li>Built a multi-page React app with React Router for smooth navigation and clean URL structure.</li>
      <li>Implemented an adoption interest form that auto-fills the selected animal’s name from the gallery.</li>
      <li>Created reusable UI components for pet profiles, stories, and forms for consistency and maintainability.</li>
      <li>Designed a responsive layout with subtle animations for a warm, approachable experience.</li>
    </ul>

    <p class="project-section-title"><strong>Impact</strong></p>
